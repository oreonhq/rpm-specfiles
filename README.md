# Oreon RPM Specfiles

This repo contians all the source specs for Oreon 11 and parts of Oreon 10. Source RPMs with the tarballs can be found on [our package mirrors](https://rsync-mirror-view.oreonhq.com/) which will be in `src` directories. We do not store tarballs in THIS repo in most cases.

## Packaging standards
You can find our packaging standards [here](https://wiki.oreonhq.com/docs/policies/packaging) on the Oreon Wiki.

## Contribute
We are actively looking for people to help with packaging. You can apply [here](https://tally.so/r/XxK45Y). You may also contribute via PRs.
