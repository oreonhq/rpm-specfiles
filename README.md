# Oreon RPM Specfiles

![GitHub commits](https://img.shields.io/github/commit-activity/t/oreonhq/rpm-specfiles)
![GitHub last commit](https://img.shields.io/github/last-commit/oreonhq/rpm-specfiles)
![GitHub contributors](https://img.shields.io/github/contributors/oreonhq/rpm-specfiles)

This repo contains all the package source specs for Oreon 11 and parts of Oreon 10. Source RPMs with the tarballs can be found on our [package mirror(s)](https://rsync-mirror-view.oreonhq.com/) which will be in `src` directories. _We do not store tarballs in this repo in **most cases.**_

## Packaging standards
You can find our organization's packaging standards [here](https://wiki.oreonhq.com/docs/category/packaging) on the Oreon Wiki.

## Contribute
If you believe you can help us in packaging, please apply [here](https://tally.so/r/XxK45Y). We are actively looking for people to help with packaging, but you can always open a pull request.
