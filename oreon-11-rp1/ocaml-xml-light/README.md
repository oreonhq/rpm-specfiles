# ocaml-xml-light

[Xml-Light](http://tech.motion-twin.com/xmllight.html) is a minimal XML parser
&amp; printer for OCaml.  It provides functions to parse an XML document into
an OCaml data structure, work with it, and print it back to an XML document.
It also supports DTD parsing and checking, and is entirely written in OCaml;
hence it does not require a C library.
