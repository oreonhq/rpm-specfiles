    네이버 클리어타입 컨트롤 제거 방법은 일반 프로그램 제거 방법과 동일
    합니다.

     

    1. Windows 작업 표시줄에서 시작 > 제어판을 선택합니다.
    2. 제어판에서 프로그램 추가/제거를 실행합니다.
    3. 현재 설치된 프로그램: 목록에서 네이버 ActiveX 가이드를 선택하고
    변경/제거를 클릭합니다.

     

     

    4. 다음과 같은 제거 안내 창이 나타나면 다음을 클릭합니다.

     

     

    5. 나타난 ActiveX 목록에서 네이버 클리어타입 컨트롤을 선택하고 제거
    를 클릭합니다.

     

     

    6. 인터넷 브라우저가 실행 중인 경우 아래와 같은 창이 나타납니다.

        이 창에서 확인을 클릭하면 사용 중인 웹 브라우저가 종료되고 네이
    버 클리어타입 컨트롤을 제거합니다.

     

     

    7. 네이버 클리어타입 컨트롤 제거가 완료되면 마침을 클릭합니다.

     

     

    ※ 네이버 클리어타입 컨트롤을 제거하더라도, 글꼴 가장자리 처리 방식은
    클리어타입으로 유지됩니다.

        만약 클리어타입 설정을 사용하지 않으려면 글꼴 가장자리 처리 방식

  * 컴퓨터에서 네이버캐스트가 나눔글꼴로 보이지 않습니다. 왜 그런가요?
    <#도움말보기>
    목록보기 <javascript:view_list('14001');>

     

    네이버캐스트는 운영체제가 Windows XP 또는 Windows Vista이고

    웹 브라우저가 Internet Explorer 6.0 버전 이상일 경우에만 나눔글꼴로
    표현됩니다.


    위에서 설명한 운영체제를 사용하지 않고 나눔글꼴을 사용하면 클리어타
    입(Clear Type) 설정이 적용되지 않고

    한자가 표현되지 않아 가독성이 떨어집니다.

    따라서 네이버캐스트는 다른 운영체제에서 나눔글꼴로 표현되지 않습니다.


    별도로 나눔글꼴을 설치할 필요 없이 웹 브라우저에서 나눔글꼴을 보려면
    웹 브라우저가 웹 폰트(.eot)를 지원해야 합니다.

    이를 지원하지 않는 웹 브라우저(Firefox, Chrome, Opera, Safari 등)는
    나눔글꼴 대신 시스템 기본 글꼴을 표시합니다.
